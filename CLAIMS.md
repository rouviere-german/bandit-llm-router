# Claims and evidence

Every claim in README.md maps to a test, a bench script or a CI job. `scripts/check_baseline.py` fails
if a backticked reference below points at a file, test function or CI job that does not exist. Local
commands run offline with no API key; rows marked **CI** are verified only in GitHub Actions.

The numbers in the README's Results section are not claims made here -- they are outputs. Rows 24-30
below say which bench produced each number and which threshold in `bench/thresholds.json` fails CI if
it regresses.
